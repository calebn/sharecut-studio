## Podcast listing (Deliver section)

The Podcast listing shows the episode as a podcast app will show it, read from the feed service. Clicking a value edits it in place (Enter saves, Esc cancels) and it shows **Edited** at once; a value the service refuses goes back to the saved one with the reason in plain words under a banner, naming the field by its label (for example "Hosting address must be an https address, using plain letters and numbers."); an Editor reads the same sentence as the host. A setting the listing does not show in place is asked for in a small form that uses the field's label and a Yes/No choice for yes-or-no settings (a setting that can only be switched on, such as hiding the show from directories, offers only Yes; clearing it turns it off). **Write feed file** appears only when the file on disk is out of date. If the listing cannot be read it says "Could not load the listing" with **Try again**.

**Who sees what.** The host edits everything and also sets up or chooses the show. An Editor link opens Deliver with this listing alone, edits episode and plain show values and writes the file; the show, the show's hosting address template and local artwork read "Only the host can change this.", and the values an Editor wrote carry a **Guest** mark. A Viewer or Commenter link has no Deliver stage; the read-only listing ("This link can read the listing but not change it.") exists for links that may read it.
