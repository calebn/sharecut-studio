## Host: Connect agent dialog

| | |
|--|--|
| **Purpose** | Copy the local connection address so an AI app can use the running Studio |
| **Open** | Project menu → **Connect agent…** (`mcp.connect`); Home app menu (the wordmark) → **Connect agent** |
| **Primary actions** | **Copy address** (for example `http://127.0.0.1:8765/mcp`; the port can differ, and the dialog shows the real one; focused when the dialog opens) · **Copy config** (the `mcpServers` JSON). Both buttons are 44 px tall with a mouse as well as touch. After a copy the button reads **Copied** and a status line says "Copied address" or "Copied config"; both clear after 2 seconds, and a second copy restarts the 2 seconds. Focusing or clicking the address or the config selects all of it |
| **Data shown** | A lead ("Keep ShareCut Studio running while your AI app uses it. The app works on the episode you have open."), three steps (copy the connection address, paste it into the AI app's MCP or connector settings, ask the app to do something in ShareCut), the **Connection address** field with the hint "The MCP server address for this computer.", the config (**Configuration (JSON)**) behind a closed **Config file format** disclosure (44 px summary), one **Setup guide (opens in a new tab)** link to the docs site, and a last-used line. The dialog names no specific app |
| **Last-used line** | One line is reserved under the address so the first answer does not shift the dialog; at 320 px or large text a long sentence wraps to a few lines. Studio asks every 3 seconds, only while the dialog is open and the tab is visible, and again at once when the tab comes back. Five states: blank until the first answer (or when the check fails: it keeps what it last said); "No app has used this address since Studio started."; "An app used this address just now / 1 minute ago / N minutes ago." up to 10 minutes; "Last used N minutes / 1 hour / N hours / 1 day / N days ago." after 10 minutes, in the same neutral tone (no colour, icon or "not connected"); and the unavailable state. The minutes count up on their own between answers. "Used" means the host answered a valid request at the address, so it never says "connected" or "online": any local program counts, and Studio keeps no session to know an app is still there |
| **Announcements** | The line is not a live region. A separate screen-reader-only polite status speaks the new sentence only when the state changes between two known states (never the first one after opening, never a minute ticking over, and never a duplicate of the unavailable explanation when it receives focus; the one change that arrives with no new answer is "An app used" becoming "Last used" when the clock passes 10 minutes), and clears after 2 seconds. It is apart from the "Copied" status, so neither overwrites the other |
| **Empty / error** | No episode open: the address still copies, and the dialog says "Open an episode first. Your AI app has nothing to work on until you do." (a status note above the address). Unavailable (this copy of Studio is not set up to accept connections from other apps): the dialog says so in plain words, hides the steps, address, config and copy buttons, keeps the setup link and Close, and stops asking. If the focused control disappears, focus moves to the explanation. If focus stays on a surviving control, the polite status announces the change. If the browser refuses a copy (or has no clipboard) the dialog says, for every cause, "Couldn't copy. Select the text and copy it by hand."; it replaces any "Copied" label and stays until the next copy or close |
| **Phone** | Stacks lead, steps, address, last-used line, disclosure and link in one column; the footer buttons stay pinned. Summary and link are 44 px tall; nothing scrolls sideways down to 320 px; opening the config keeps the address in the same place within the panel |
| **Out of scope** | Writing a client's config file; PATH-installing `podcast-mcp`; guest share-token MCP (that stays on Share…); knowing that an app is still connected; naming apps; push updates instead of asking; a separate Home warning (Home shows the note above because no episode is open there, and that is correct) |

Guest share agents use `{base}/mcp/{token}/mcp`.
