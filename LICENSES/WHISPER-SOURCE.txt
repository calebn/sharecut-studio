What the app contains

The iOS app embeds one dynamic framework, Whisper.framework, that runs the
whisper.cpp command line tool inside the app process. It is built from the
source below, with the patch pinned in contracts/whisper-build.json in the
application source repository. whisper.cpp and ggml are licensed under the MIT
license, which is reproduced below and ships with the app.

  whisper.cpp v1.9.5   MIT
    https://github.com/ggml-org/whisper.cpp
    commit d1be6fde11ac6e0407606b4e42fe72d34add8037
    sha256 of the pinned source archive: see contracts/whisper-build.json

Changes to the upstream sources

The patch patches/whisper-cli-hooks.patch (gui/desktop/src-tauri/ios/whisper)
replaces the example's abort callback and encoder-begin callback so a running transcription
can be cancelled, removes the runtime scan for ggml backend libraries, removes
an unused call to system(), makes an unknown language exit with status 1, and
compiles out of iOS builds the part of ggml.c (ggml_print_backtrace) that
starts a debugger by fork and exec to print a backtrace.
